# Contributing

Use Node 22.22.0 and pnpm 10.18.2. Install with `pnpm install --frozen-lockfile`. Keep changes focused, preserve local resume data and never add personal examples, credentials or environment files to a public contribution.

Run `pnpm check`, then `pnpm test:browser` after installing all three Playwright browsers. Document actual results and any limitations. The browser suite builds a copied React fixture; preserve the portable component boundary. Regenerate and inspect every enabled PDF after content or print changes.

Describe the user-visible problem, the change and verification in a pull request to the selected template repository. Report ordinary bugs with reproduction steps, runtime versions and fictional sample data. For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
